# 📚 The Polite Scraper — Books to Scrape

A robust, polite, and modular web scraper built with Python to extract structured data from [books.toscrape.com](https://books.toscrape.com/). Designed following professional software development practices, featuring local file caching, strict data validation with **Pydantic**, network health checks, automated unit testing with **pytest**, and multi-format data export (JSON & CSV).

---

## 🎯 Target Classification & Lane

* **Target Site:** `https://books.toscrape.com/`
* **Classification:** Static HTML / E-commerce Sandbox.
* **Lane:** Pure HTTP requests + BeautifulSoup parsing (`requests` + `bs4`). 

> **Why no browser automation (Selenium/Playwright)?**  
> The target data is already present in the raw HTML sent by the server. Using a full browser automation tool like Playwright or Selenium would only introduce unnecessary memory overhead, resource cost, and slow down execution.

---

## 🛠️ Politeness Rules

This scraper strictly follows ethical and polite scraping practices:
* **User-Agent:** Custom descriptive User-Agent header (`PoliteScraper/1.0 (+portfolio-project)`).
* **Delay:** `0.5` seconds artificial delay (`time.sleep`) between network fetches to prevent server overloading.
* **Timeout:** `10` seconds HTTP timeout to avoid hanging connections.
* **Cache:** Local SHA-256 disk caching (`.data_cache/`) to avoid repeating HTTP requests during re-runs or development iterations.

---

## ⚠️ Honest Limitation

* **Static Pagination Bound:** The parser relies on relative HTML link structures (`li.next > a`). If the website dynamically renders pagination via JavaScript or changes the underlying table class names (`table.table-striped`), the DOM selector logic would require updates.

## 🚀 One Copy-Pasteable Run Command

Ensure you have your virtual environment activated and dependencies installed, then run:

```bash
python -m src.main
```
